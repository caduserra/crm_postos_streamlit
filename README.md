# CRM Gas Stations

Este é um **CRM simples para postos de combustíveis**, desenvolvido em **Python** usando **Streamlit**, **SQLite**, **Pandas** e **Plotly**.  
Permite: cadastro de clientes, atualização de etapas, controle de pagamento e visualização de funil de vendas.

---

## **Funcionalidades**

- Adicionar clientes com informações:
  - Nome
  - Contato (email/telefone)
  - Status (Lead/Client)
  - Etapa (Pré-venda, Implantação, Pós-venda)
  - Mensalidade
  - Próximo pagamento
  - Status do pagamento (Pendente, Pago, Atrasado)
  - Observações
- Atualizar informações de clientes
- Visualizar tabela de clientes
- Visualizar funil de vendas por etapa com cores diferenciadas
